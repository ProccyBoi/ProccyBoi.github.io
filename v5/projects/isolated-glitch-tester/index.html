Two ways to detect a fault

The isolated input is split into a path for slow changes and a path for brief disturbances.

Drift

A low-pass filter follows slow voltage changes. An LM339 window comparator checks the filtered voltage against the upper and lower drift limits.

Spikes

The second path catches short excursions outside the selected ±75 mV or ±150 mV window.

Hold the indication

The CD4043 latch holds an indication after the comparator output clears. The board also breaks out oscilloscope signals and provides separate reference adjustments and a buzzer mute.

The virtual bench uses synthetic signals to illustrate the controls and indicator behavior.

Model sources

The assembly follows the v04 KiCad layout. The inspector identifies the model source and footprints marked do-not-populate.
