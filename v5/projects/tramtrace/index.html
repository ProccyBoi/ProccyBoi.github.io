01 / The work

From station data to the right physical LED

Assembled hardware + published firmware

My contribution

PCB design, embedded display logic and the vehicle-position service for the light-rail map.

The task

Fit four light-rail lines, station labels and 116 RGB pixels onto a compact PCB, then map each live station state to its electrical position.

Design decisions

The hardware cross-reference links printed stations to LED chain indices. It explicitly handles the shared L2/L3 trunk and L1 Central's single route pixel.

An ESP32 and level shifter drive five LED chains. Firmware caps route brightness and the hardware-test sequence lights one route pixel at a time.

The service tracks source freshness and caches the last good data; the board clears an expired frame after 60 seconds.

What has been checked

The build photographs show the assembled, illuminated map. Published mapping tests compare the 68 route/station entries with the firmware bindings, check pixel coverage and check the shared-route exceptions.

Result and next step

The physical display is accompanied by public firmware, a traced station-to-pixel map, service code and test code. The documented test-pairs sequence provides a station-by-station check of the displayed direction convention.

Read the detailed project notes

Metroboard's sibling

Metroboard covered Sydney's heavy-rail network, so the obvious follow-up was the tram network. TramTrace squeezes the CBD and Parramatta lines onto a smaller board without turning the route into an unreadable knot.

The board joins Wi-Fi and gets vehicle positions from a small service I wrote. The LEDs then turn those positions into something I can read at a glance from across the room.

On the board

An ESP32-WROOM-32E handles the network connection and display logic. A CH340C gives me a straightforward USB programming path, while level shifting keeps the ESP32 and LED data happy together.

The hard part was physical rather than computational: the station names, route geometry and components all had to share the same compact board. The silkscreen ended up doing real work as part map, part assembly drawing.
