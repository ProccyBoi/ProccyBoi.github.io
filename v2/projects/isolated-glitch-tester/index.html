Isolated Glitch Tester v04

A PCB designed to distinguish slow voltage drift from brief spikes, with separate high and low fault indicators.

Explore the 3D board Try the signal demo

Board and components

Turn the board to see both sides. Pick a footprint on the board or search by reference or value to open its own 3D view.

Signal demo

Inject drift or a spike and see which fault indicators latch. Change the spike threshold or reset the indicators between runs.

Detection paths

The schematic shows a differential input stage feeding separate drift and spike comparator paths. Each path has high and low fault indicators. The board brings signals out to oscilloscope connectors and provides reference adjustments, an arm/reset control and a buzzer mute.

The 3D assembly uses the v04 KiCad layout. The inspector identifies each model’s source and flags footprints marked do-not-populate in the design. 3D model credits
