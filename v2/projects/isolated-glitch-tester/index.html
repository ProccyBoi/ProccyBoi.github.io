Signal demo

Run a spike or a drifting signal and see which indicator latches. Arm / Reset clears the indicators for the next capture.

Two ways to detect a fault

The isolated input feeds two detection paths. A low-pass filter tracks drift, while the spike path catches short excursions. An LM339 compares both paths against high and low limits.

The four comparator outputs feed a CD4043 latch, so a momentary fault stays visible until reset. The board also breaks out signals to an oscilloscope and provides separate reference adjustments and a buzzer mute.

Model sources

The assembly follows the v04 KiCad layout. The inspector lists each model’s source and identifies the footprints marked do-not-populate. KiCad model credits and reconstruction sources.
