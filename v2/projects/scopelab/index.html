A browser-first teaching bench

ScopeLab gives students a single place to work through microcontroller fundamentals: edit the supplied TypeScript, compile it in the official micro:bit editor, flash a BBC micro:bit V2 in a supported browser, then measure the resulting signal.

Open ScopeLab →

Student workflow

  • Choose a GPIO, UART, I2C or SPI lab with wiring and scope setup guidance.
  • Edit and build the starter program in the embedded official MakeCode editor.
  • Pair and flash the board directly from a current Chromium-based desktop browser.
  • Probe the assigned pins and decode the waveform on an oscilloscope or logic analyser.

Bench requirements

Use a BBC micro:bit V2, a data-capable Micro-USB cable, an edge-connector breakout, jumper wires and an oscilloscope with digital channels or a logic analyser. The optional I2C lesson uses a TMP102-compatible sensor at address 0x48. All signals are 3.3 V.

Direct flashing is supported in current Chrome and Edge on desktop. Other browsers can still build and download a .hex file for manual transfer to the MICROBIT drive.
