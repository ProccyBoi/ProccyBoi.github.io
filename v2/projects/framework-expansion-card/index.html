A laptop-bay dev board

I liked the Framework expansion-card system, but I wanted a module that could do more than expose another laptop port. This one puts an ESP32-S3-MINI-1 in the bay and leaves the radio visible through a clear shell.

The 0.6 mm board thickness is part of the electrical design as much as the mechanical one: it lets the card mate with the laptop's USB-C connector without a separate plug or interposer.

The latest revision swaps the original green board for black solder mask and white silkscreen. It is now assembled in the clear enclosure, with the antenna end of the ESP32 left unobstructed.

Programming and power

A CH340K provides the USB serial connection. The BC817 transistor pair handles automatic boot and reset, so uploading firmware feels like using a normal development board rather than a bare module.

An AMS1117-3.3 supplies the ESP32. None of those parts are exotic; fitting them, the USB routing and the module keep-out into the expansion-card outline was the real exercise.
