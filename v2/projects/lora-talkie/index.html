LoRa Talkie

A pocket radio that writes one-button Morse messages and sends them over LoRa.

Personal project

The interaction
Write, edit and send a complete Morse message with one button.
The link
915 MHz LoRa on a Heltec V3 board with an SX126x radio.
The field workflow
Continuous receive, message recall, a status page and beacon mode.

One button, full messages

LoRa Talkie normally sits in receive mode and prints incoming messages straight to its OLED. A double-click opens the composer, where the same program button becomes a Morse key. I added dedicated patterns for spaces and deleting the last character so a complete message can be written without a keyboard.

A two-second hold sends the message and returns to the chat screen. The device remembers the last four outgoing messages; they can be selected with one to four clicks, edited and sent again.

Radio and field controls

The current radio profile uses 915 MHz LoRa with a 250 kHz bandwidth, spreading factor 12 and up to 22 dBm transmit power. After each transmission the firmware puts the radio straight back into continuous receive mode.

The status page shows battery voltage, the configured frequency and spreading factor, transmit power and board temperature. There is also a repeating beacon mode for link checks, battery and temperature safety cut-offs, and deep sleep for carrying the unit without running it flat.

The OLED interface is deliberately small but not purely functional: it has startup and shutdown animations, plus coin, dice and slot-machine diversions that use the same single-button control scheme.
