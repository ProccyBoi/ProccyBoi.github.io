Two ways to detect a fault

The differential input feeds two paths. A low-pass filter tracks slow drift, while a separate path responds to brief excursions. An LM339 comparator drives four independent indicators through a CD4043 latch, so a momentary fault stays visible until reset.

The board has reference adjustments for drift and spike detection, oscilloscope outputs, and a buzzer mute.

Model sources

The assembly follows the v04 KiCad layout. The inspector lists each model’s source and identifies the footprints marked do-not-populate. KiCad model credits and reconstruction sources.
