A range result, and a better RF question

01My contribution

A receiver PCB combining an ESP32 application controller, 915 MHz LoRa and a u-blox NEO-M9N GNSS receiver.

02The constraint

Putting radio and navigation on one board reduces external wiring, but makes the feedline layout part of the system design.

03Design decisions

Check the Rev A feedline with a VNA. Its mismatch from the 50 Ω target informed a dedicated RF test board for comparing geometries and transitions.

04Evidence & validation

The published case records a link reaching at least one kilometre in testing, alongside the VNA investigation of the first-pass feedline.

05What this does not establish

The distance is a reported test result. The page does not publish a complete range-test setup, packet-loss curve or measured impedance value.
