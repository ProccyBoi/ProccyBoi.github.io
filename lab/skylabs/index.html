What the board actually does

One packet,
four useful exits.

  1. 01

    Receive

    The SX1262 listens on 915 MHz and hands each valid air-link packet to the ESP32 over VSPI.

  2. 02

    Record

    The shared SPI microSD stores every accepted packet as readable CSV or an indexed, CRC-protected binary log.

  3. 03

    Present

    The ESP32 serves a local captive dashboard and streams live telemetry to a computer over USB serial.

  4. 04

    Reply

    Record, pause and marker commands return to the aircraft as short repeated LoRa command bursts.

Firmware, made physical

The board is more than a radio receiver.

915
MHz LoRa link
100
ms default packet interval
230400
baud USB serial stream
20
MHz primary SD clock

The radio and SD card share the ESP32's VSPI bus. Their chip-select lines are managed explicitly so logging cannot hold the radio off the bus while a packet is waiting.
