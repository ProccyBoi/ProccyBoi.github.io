The shell is rendered from Framework's expansion-card enclosure STL. The board is a KiCad GLB export of the actual 0.6 mm design; the ESP32-S3-MINI-1 uses Espressif's official 3D model, and the USB-C plug uses the exact legacy KiCad Molex 105444 CAD model. Marking controls expose the complete KiCad silkscreen, assembly/fabrication linework and user drawing layers; display strokes are intentionally heavier than manufacturing line width for screen legibility.
