- F110211 diagnostic: https://proccyboi.github.io/proccy-boi/reports/f110211/diagnostic.html

## Publishing another page

1. Add the page under a stable folder, such as `reports/example/index.html`.
2. Add its media beside the page or under `assets/`.
3. Add a link or report card to the root `index.html`.
4. Commit and push to `main`; GitHub Pages publishes the update automatically.

The F110211 report contains the exact GPS track recorded during the flight.
